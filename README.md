# Постер

Заполняет форму ролика в твоём Chrome: видео, текст, хэштеги, время отложки. Кнопку «Опубликовать» не нажимает. «Запланировать» нажимает только когда дата и время в полях уже совпали.

Сейчас включены TikTok, Instagram, YouTube Shorts и VK Клипы (ссылка на клипы сообщества — поле `vk_url` в панели). В Chrome этого профиля нужно быть залогиненным в ту сеть, которую запускаешь.

## Первый запуск

```bat
Z:\ai\bridge\venv\Scripts\python.exe -m pip install -r requirements.txt
start_panel.bat
```

`playwright install` не нужен: браузер не скачивается, скрипт подключается к уже открытому Chrome.

В панели:

1. Проверь путь к `chrome.exe`, профиль `chrome_profile` и порт `9333`.
2. Нажми «Запустить Chrome» и залогинься в TikTok сам.
3. Положи в `posts` пару `001.mp4` и `001.txt`. Хэштеги — в `001.tags.txt`. Обложка — `001.jpg` или `001.cover.jpg` (как у TikTok). Для VK Клипов: в панели `vk_url` — кабинет **SINTEZ.SPACE** (Клипы) и **`vk_channel_name`** — имя в модалке «Новый клип» (VK иначе шлёт в последний канал, например SYNTHESIS[education]) (например `https://cabinet.vkvideo.ru/dashboard/@public…?section=video_my_content&subsection=video_my_content_clips`); скрипт сам жмёт «Добавить» → «Создать клип». Для Instagram: коллабораторы в `001.collaborators.txt`, теги на рилсе в `001.reel_tags.txt` (логины через запятую в одной строке), либо две такие строки в `posts/instagram.txt`, либо поля в панели. Для YouTube: название до 100 символов в `001.youtube_title.txt` или первой строке `posts/youtube.txt` (иначе первая строка `001.txt`), описание — текст поста + хэштеги до 5000 символов; «не для детей» и открытый доступ по расписанию выставляет скрипт.
4. Укажи время первого поста и лимит `1`.
5. «Заполнить формы».

Порт `9333`, а не `9222`: на `9222` часто уже сидит другое окно Chrome.

## Что делает скрипт

Открывает новую вкладку на странице загрузки TikTok Studio, подаёт файл, очищает предзаполненное имя ролика, вставляет текст. Если подсказка хэштега мешает, вставляет хэштеги по одному и закрывает подсказку Escape. Потом включает отложку и пишет дату и время. Вкладку не закрывает.

Если страница просит проверку или капчу, скрипт останавливает эту сеть и пишет об этом. Капчу не обходит.

Ошибка одного поста не останавливает остальные. Снимок лежит в `errors/<сеть>_<имя>/`: `error.json`, `page.html`, `page.png`, `aria.txt`, `accessibility.json`.

## Команда без панели

```bat
python poster.py --sites tiktok --limit 1 --when 2026-10-27T18:00
python poster.py --dry --sites tiktok --limit 1
python poster.py --sites tiktok --limit 1 --adapt --headed-slowmo 400
```

`--dry` печатает тексты и не открывает браузер. `--adapt` гоняет текст в LM Studio на `http://localhost:1234`. Другие адреса отклоняются.

Селекторы, адреса и лимиты символов — в `sites.json`. Логика их не дублирует.
